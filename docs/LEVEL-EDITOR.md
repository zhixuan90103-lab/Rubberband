# 关卡卡组

桌面预览里的摆钉工具，也是有存档时正式爬塔的关卡数据。实现在 `src/editor/`，播放在 `src/game/deckRun.ts`。不改手感，不改发射公式。跳跃、抓取、贴墙的数字以 `src/game/tune.ts` 和 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md) 为准。调参面板改过 `feel` 之后，编辑器里的圈跟着当前值变。

坐标和游戏一致：设计空间 **390×844**，**+x 向右，+y 向下**。一张卡的本地 `y = 0` 是这一屏的顶。玩家往更小的世界 `y` 爬。

## 什么时候用卡组

桌面验收只开 http://127.0.0.1:5207/ 。不要用局域网 IP，那个地址没有 WebGPU。代码不按网址决定钉从哪来。

开局只用开局卡一次。其后每一张名字不以「衔接」开头的普通卡都参加抽取，编辑器标成「不能入组」也不排除。抽完再洗，没有终点。编辑器草稿存在 `rubberband.levelDeck.draft`，游玩优先读这份。旧钥匙 `rubberband.levelDeck.v1` 只在没有草稿时被读一次。没有草稿时用 `levelDeck.json`。

读档经过 `adoptDeck`：名字正好是「红点金币1」「红点金币2」「红点金币3」的卡标上系列 `红点金币`。不按钉 id 改坐标。

编辑器只在桌面预览出现。右上角「关卡」，或地址加 `?editor=1`。打开时把当前文档写回存档。

## 卡和卡组

一张卡是一屏里的铆钉和金币，外加名字。

| 种类 | 用途 |
|---|---|
| 开局卡 | 一场只用一次，接在最底下。有且只有一颗绿钉 |
| 普通卡 | 名字不以「衔接」开头。游玩时全部打乱轮抽，不看是否已放进编辑器卡组 |
| 衔接卡 | 名字以「衔接」开头。不进抽卡袋。两张普通卡的接缝超过 300 px 时，在中间插一张 |

一场没有程序生成的钉行。袋抽完再洗。摆不下整张卡时游标退回，等下面的钉回收后再摆，不丢卡上的任何一颗钉。

卡组在编辑器里仍是一袋，用来看接缝。权重和「红点金币」系列不参与现在的游玩抽卡。手工标签只有「左重」「右重」，只用于列表筛选。

容量：普通卡最多 6 颗钉、2 枚金币。开局卡另计那颗绿钉。活钉槽 `PEG_POOL` 24，金币槽 `COIN_POOL` 8，编辑器不把池子加大。

## 能跳、同排、出口和入口

钉心到钉心的直线距离。

- 短于 **`PEG_JUMP_MIN`（200）** 的向上一跳太近。
- 长于 **`PEG_JUMP_MAX`（600）** 拉满也到不了。
- **同排**是高度差不超过 `2 × PEG_ROW_STAGGER`（44 px）。同排可以比 200 更近，不当成一跳，也不标太近、抓取重叠、瞄准重叠。

`canClimb`：目标更靠上、不在同排、距离落在 200 到 600。

- **出口** `climbExits`：非绿钉，并且没有一颗能从它再往上跳。绿钉不是出口。开局第一跳是绿钉到这张卡上的蓝钉，下一屏从那些蓝钉离开。
- **入口** `climbEntries`：非绿钉，并且没有别的钉跳到它身上。

一张普通卡没有入口或没有出口，不能进卡组。开局卡绿钉不是一颗，或没有蓝钉出口，也不能当开局用。

## 看得见下一颗

挂住时，身体在钉心下面 `restDrop`（60 px），镜头把身体放在画面高度的 `pegAnchor`（0.7）。从这颗钉再往上，下一颗钉心最多再高大约 **`hangRise`（331 px）**，才会露在顶上树叶下面。树叶大约盖住画面顶 200 px。再高，钉还在场上，但挂住之后看不见。

卡内的相对位置按编辑器原样摆，不在运行时删钉或改某一颗的坐标。卡内一跳若高于 `hangRise`，挂在下面那颗上就看不见上面那颗。这种空档要在编辑器里拆开。

## 接缝和游戏里的叠卡

编辑器的接缝预览假设下一张卡的本地 `y = 0` 在当前卡顶边再往上 844 px。出口 A 和入口 B 的距离是 `hypot(dx, 844 + A.y - B.y)`。接缝模式只画出口和入口。

游玩用同一套距离，取最高出口到最近入口的最短一条：

- **不超过 300 px**：下一张卡的本地 `y = 0` 仍在上一张上方 844 px。若这样会把入口钉送进树叶，整张卡下移，直到那颗入口刚好落在 `hangRise` 上。卡内相对位置不动。
- **超过 300 px**：中间插一张衔接卡。衔接和后面那张普通卡都收到 300 px 以内，按最高出口对准入口里横坐标最接近的那颗。
- **衔接1 不紧挨衔接2**。上一张已经是衔接时，下一次仍用同一张衔接。

一张卡上的非绿钉全部摆上。槽满就整张退回，不摆半张。卡组游玩的保留带比补钉线再高一整屏（844 px），避免一张高卡的顶钉在下一帧被收回。

## 编辑

画布 390×844。身体中心最外停在大约 **x = 24** 和 **x = 366**。朝墙要能拉开 `restDrop + minPull`（85 px），所以钉心大约要落在 **x = 109 到 281**。更靠外会标「贴墙」，并且挡住进卡组。

能做的事：

- 点选、拖动、删除。空白处拖出框选，Shift 追加。方向键 1 px，Shift 加方向键 10 px，作用在整组选中的点上。
- 坐标栏改横坐标、纵坐标。选中的点在这一轴上不一致时，框是空的，占位写「多个」；回车把这个数写到所有选中点。
- 「这一排对齐并平分」：多选时用它们的平均高度，按 390 的宽度等分。三颗钉落在 x = 65、195、325。这两侧会贴墙，图上会标出来。只选一颗时，把高度差在 80 px 以内的钉收成同一排再等分。
- 添加蓝、红、绿钉和金币。绿只在开局卡，且只有一颗。复制开局卡会变成普通卡，绿钉改成蓝钉。
- 撤销和重做，大约 40 步。
- 列表里新建、重命名、删除、放进或拿出卡组、改权重。开局卡不能删。
- 选中钉画实线 200 / 600 环，并向上画能跳、太近、太远。同排不画。

金币是卡上的点。有卡组时不再用 `jumpsUntilCoin`。运行时仍只在向上的发射或飞行里捡，拾取半径 `COIN_PICKUP + BODY_RADIUS`（72 px）。

## 标记

能存。标在钉或金币上，并收进这张卡的问题列表。

| 标记 | 条件 | 挡住进卡组 |
|---|---|---|
| 太近 | 不同排，距离 &lt; 200 | 是 |
| 太远 | 不是出口，往上 600 px 内没有下一颗；或接缝失败 | 是 |
| 贴墙拉不开 | 钉心到 x=24 或 x=366 的水平距离 &lt; 85 | 是 |
| 没有入口或出口 | 见上面的出口、入口 | 是 |
| 绿钉数量不对 | 开局卡不是正好一颗 | 是 |
| 抓取叠在一起 | 不同排，距离 ≤ `2 × grabRadius`（默认 90） | 否 |
| 瞄准会失效 | 不同排，距离 ≤ `2 × (grabRadius + AIM_EXTRA)`（默认 140） | 否 |
| 红钉在必停点 | 这颗红钉是唯一出口，或拿掉它就到不了出口 | 否。红钉挂着 3 秒后变灰松开，蓝钉 5 秒 |
| 金币捡不到 | 没有任何一颗更低的钉，能用一次向上的发射让身体中心进 72 px | 否 |
| 金币压在钉上 | 金币到任一钉心 &lt; 36 | 否 |

同排不标太近、抓取重叠、瞄准重叠。

## 衔接卡

游玩认的衔接卡是文档里名字以「衔接」开头的普通卡，目前是衔接1 和衔接2。它们不进抽卡袋。`src/editor/bridgeCards.ts` 里的 `bridge-1` … `bridge-10` 不合并进这份文档，也不参加抽取。

## 这一版不做

- 不在编辑器里试玩物理。环、跳线和接缝是摆放是否合理的依据。
- 不编辑墙、手感、钉的存活秒数。
- 不多屏连成一张长卡。
- 不替换金币或铆钉贴图。
- 溶解、移动钉、额外障碍、音效仍不做。
