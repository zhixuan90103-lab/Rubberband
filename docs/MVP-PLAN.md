# 拉射范围

手感数字只写在 [SLING-KONG-FEEL.md](./SLING-KONG-FEEL.md) §7，代码在 `src/game/tune.ts`。这里只记做了什么、文件边界、以及还没做的。

## 已落地

按住、反拉、松手、飞行、抓住或坠落。固定步长 1/60 秒。

| 模块 | 职责 |
|---|---|
| `src/game/tune.ts` | 手感常数。改拉距、重力、间距、锚点只改这里 |
| `src/game/pegs.ts` | `nextPeg(prev, rng, id)` 是唯一摆钉入口 |
| `src/game/sling.ts` | `hang` / `drag` / `fly` / `fall`，以及镜头 |
| `src/game/selftest.ts` | 短拉取消、拉满向上、旧钉锁、生成钉能被抓住 |
| `src/main.ts` | WebGPU 场景、两只手臂、钉子外观、指针 |

摆钉：`nextPeg` 的竖直间距 100–130 px，左右散开后仍在竖道内。当前钉之上保留 4 颗。换固定关卡或飞行钉时只替换这个函数。

拉射：起拖在身体 48 px 内，并用 `setPointerCapture`。拉距按悬挂姿势量，短于 28 px 取消，超过 160 px 夹住。松手沿反方向飞出。手进入钉子 36 px 内才抓住。刚松开的钉子锁 0.18 秒。飞出竖道、没抓住并掉出镜头下方，进入坠落；点一下用下一个种子重开。

画面：身体在钉子下方，两只手臂在悬挂和拖动时都看得见。松手时旧钉闪一下，飞行中身体旋转，抓住时压扁再回到悬挂。蓝钉和红钉只差颜色。瞄准时镜头停在悬挂点。

底座仍在：`clientToDesign`、设计尺寸正交相机、`DoubleSide`、`base: './'`。`OrbitControls` 和挡住拖动的底部面板已经去掉。

## 验收

```bash
npx tsc --noEmit
npx tsx src/game/selftest.ts
```

自测覆盖：短拉取消、向下拉满后向上飞、生成的钉子能抓住、锁定期内抓不回刚松开的钉。

浏览器里再看一遍：悬挂时能看见身体、两臂和上方四颗钉；拉短取消；拉满能抓住或坠落；坠落后再点能重开。无头 Chrome 画不出这块 WebGPU 画布，不能用它的截图当验收。
