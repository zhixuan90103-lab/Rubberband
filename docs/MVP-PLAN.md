# 拉射范围

手感数字只写在 [SLING-KONG-FEEL.md](./SLING-KONG-FEEL.md) §7，代码在 `src/game/tune.ts`。这里只记做了什么、文件边界、以及还没做的。

## 已落地

按住、拉长、松手、收回、飞行、抓住或坠落。固定步长 1/60 秒。同一具身体，重力一直在。规则见 [SLING-KONG-FEEL.md](./SLING-KONG-FEEL.md) §7。

| 模块 | 职责 |
|---|---|
| `src/game/tune.ts` | 手感常数。改拉距、弹簧、阻尼、重力、间距、锚点只改这里 |
| `src/game/pegs.ts` | `nextPeg(prev, rng, id)` 是唯一摆钉入口 |
| `src/game/sim.ts` | Rapier 2D。重力、收回和飞行的积分、左右墙。不管悬挂 |
| `src/game/sling.ts` | `hang` / `drag` / `return` / `launch` / `fly` / `fall`，软带，以及镜头 |
| `src/game/selftest.ts` | 死区、上下发射、竖道不折弯手臂、旧钉锁、冲过钉子、绕钉回弹 |
| `src/main.ts` | WebGPU 场景、两只弯手臂、钉子、镜头横线、指针 |

摆钉：只有两颗，都在竖道中线。下面那颗是起点，上面那颗高出 `PEG_UPPER_GAP`。抓住上面那颗不再往前铺钉。

拉射：起拖在身体 64 px 内，悬挂、回弹、摆动中都可以按下，并用 `setPointerCapture`。手臂以当前钉子为圆心，任意方向最长都是静止长度再加 115 px。从静止姿势再拉不足 28 px，松手只回到正下方。过了死区松手后，手臂把身体拉向钉子，到松弛长度脱开再飞。身体中心进入钉子 36 px 内才抓住，同时有多颗时取最近的一颗。刚脱开的钉子从进入飞行起锁 0.18 秒，而且身体还没离开它的抓取范围时不会抓回。抓住后留下全部速度，身体冲过钉子，软带再拉回来。手留在钉子上。撞到左右墙会反弹，水平速度乘 `WALL_RESTITUTION`。飞过最下面那颗钉并且掉出镜头下方，进入坠落；点一下用下一个种子重开。

画面：手臂在悬挂、拖动、回弹和收回时从当前钉弯到两肩，飞行中脱开。松的时候弯得更开。松手时旧钉闪一下，飞行中身体旋转，抓住时压扁。死区没有额外标志，只看手臂被拉多长。现在两颗钉都是蓝色。挂着、拉动、弹回时，镜头的目标是静止悬挂点。收回和飞行的目标是身体，收回时不会跟到悬挂点以下。飞过最下面那颗钉之后目标停住。镜头用 `CAMERA_DAMP` 缓入缓出，不在一帧里启动或停住。

结束分两种。回弹和摆动是动画，按下就打断。飞行是已经提交的一发，空中不能改。坠落是这一局的规则结束，只能重开。

底座仍在：`clientToDesign`、设计尺寸正交相机、`DoubleSide`、`base: './'`。`OrbitControls` 和挡住拖动的底部面板已经去掉。

## 验收

```bash
npx tsc --noEmit
npx tsx src/game/selftest.ts
```

自测覆盖：死区内松手不发射、按下可以打断回弹、向下拉满后先收回再向上脱开、拉到钉子上方会向下发射并抓住下面那颗钉、抓住后身体冲过钉子、拉出竖道时手臂仍指向钉子、锁定期内抓不回刚松开的钉、抓住后会荡到钉子另一侧并且能被按下打断。

浏览器里再看一遍：悬挂时能看见身体、两臂、下面的起点钉、上面正中的钉；拉短取消；向上拉满能抓住上面那颗；从上面那颗向下拉能抓住下面那颗；飞过最下面那颗才坠落；坠落后再点能重开。无头 Chrome 画不出这块 WebGPU 画布，不能用它的截图当验收。
