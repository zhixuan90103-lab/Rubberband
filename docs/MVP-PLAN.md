# 拉射范围

现行规则在 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md)。代码在 `src/game/tune.ts`。这里只记做了什么、文件边界、以及还没做的。

## 已落地

按住、拉长、松手、收回、飞行、抓住或坠落。固定步长 1/60 秒。

| 模块 | 职责 |
|---|---|
| `src/game/tune.ts` | `feel`、`haptic` 和默认值。松弛长度、最长、钉位由 `feel` 算出 |
| `src/game/tunePanel.ts` | `#ui-root` 上的参数面板。写 `feel` 和 `haptic`，恢复默认 |
| `src/game/feelHaptics.ts` | 蓄力、抓住、摆动、撞墙、死亡、金币。规则在 [HAPTICS.md](./HAPTICS.md) §8 |
| `src/game/pegs.ts` | 钉的种类、计时、一行怎么摆、镜头窗口。槽位不在这里增减 |
| `src/game/coins.ts` | 金币池、间隔、摆进行距、向上才拾取 |
| `src/game/sim.ts` | Rapier 2D。重力、抓住和飞行的积分、左右墙 |
| `src/game/sling.ts` | 阶段、发射速率、抓住后的手臂力、转角、镜头、重开初速度、瞄准曲线、放大抓住、补钉和随行摆金币 |
| `src/game/selftest.ts` | 死区、上下发射速率相同、抓取、瞄准锁定、旧钉锁、墙、重开、钉场窗口、金币提前摆好 |
| `src/main.ts` | WebGPU 场景、手臂、钉子、待机、墙和阴影、指针、辅助显示、死亡界面。身体角度用 `body.spin` |

摆钉的现行规则在 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md)「摆放」和 [LEVEL-EDITOR.md](./LEVEL-EDITOR.md)。开局用开局卡。其后普通卡打乱轮抽，接缝超过 300 px 时插衔接卡，抽完再洗。活钉只覆盖镜头窗口：顶上补 `PEG_FILL_LEAD`（380 px），卡组再多留一整屏，免得高卡的顶钉被收回。槽位 24 个。数据和画面各一份，按下标对齐，空槽停到场外。铆钉画面是 41.6×39.7。层级是底盘、手臂、彩钉。蓝钉挂满 5 秒、红钉挂满 3 秒变灰，松手发射也会立刻变灰，0.5 秒后恢复。抓住时铆钉发亮，圆环向外扩开。

金币在卡上。只有向上的发射或飞行能捡，拉动时也能捡。池子 8 个。捡到后飞向左上角胶囊里的图标，数字在飞到之后才加，并响一声瞬态震动。细节在物理文档「金币」和 [HAPTICS.md](./HAPTICS.md) §8。

拉射的现行行为以 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md) 为准。包名是 `com.wangzhixuan.rubberband`，主屏幕名 Rubberband，避免盖掉别的底座包。

画面规则也在那里的「画面」一节。上下镜头用 `cameraDamp` 缓入缓出。左右镜头只在朝外拉时才偏。飞行沿速度轻微拉长，撞墙先圆再压扁，并在墙面放出一圈浅石色扩散环。掉落进入 `fall` 时镜头向下震一次，大约 0.34 秒。

结束分两种。回弹和摆动是动画，按下就打断。飞行是已经提交的一发，空中不能改。坠落是这一局的规则结束。角色隐藏，`#ui-root` 上的「再来一次」用下一个种子重开，并从掉下去的那个水平位置飞向新的出生钉。出生钉离开镜头保留带之后和其他钉一样收回，不单独留在场上。

底座仍在：`clientToDesign`、设计尺寸正交相机、`DoubleSide`、`base: './'`。`OrbitControls` 和挡住拖动的底部面板已经去掉。

## 验收

```bash
npx tsc --noEmit
npx tsx src/game/selftest.ts
```

自测覆盖：死区内松手不发射、向下拉满后脱开并向上飞、出手速率等于劲度乘伸长、向上拉满以同一速率向下飞、抓住后不超过拉长上限、拉出竖井时手臂仍指向钉子、锁定期内不抓回刚松开的钉。

浏览器里再看一遍：悬挂时能看见身体、两臂和脚下那颗绿色出生钉，再往上是正中的蓝钉；点在身体附近就能拉，猴子当帧跟手；拉短取消；向上拉满能抓住上面那颗；从上面那颗向下拉能抓住下面那颗；向上飞时，下一枚金币在进入画面之前就已经在两行之间；向下飞出画面下沿才坠落；坠落后面板点「再来一次」才重开。无头 Chrome 画不出这块 WebGPU 画布，不能用它的截图当验收。
