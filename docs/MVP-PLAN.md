# 拉射范围

现行规则在 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md)。代码在 `src/game/tune.ts`。这里只记做了什么、文件边界、以及还没做的。

## 已落地

按住、拉长、松手、收回、飞行、抓住或坠落。固定步长 1/60 秒。

| 模块 | 职责 |
|---|---|
| `src/game/tune.ts` | `feel` 和默认值。松弛长度、最长、钉位由它们算出 |
| `src/game/tunePanel.ts` | `#ui-root` 上的参数面板。写 `feel`，恢复默认 |
| `src/game/pegs.ts` | 开局四颗钉。往上只从 `nextPeg` 铺 |
| `src/game/sim.ts` | Rapier 2D。重力、抓住和飞行的积分、左右墙 |
| `src/game/sling.ts` | 阶段、发射速率、抓住后的手臂力、转角、镜头、重开初速度 |
| `src/game/selftest.ts` | 死区、上下发射速率相同、抓取、旧钉锁、墙、重开 |
| `src/main.ts` | WebGPU 场景、手臂、钉子、待机、墙和阴影、指针、死亡界面。身体角度用 `body.spin` |

摆钉：开局四颗。中线下面是绿色出生钉，在挂着的脚的位置。上面那颗高出 `PEG_UPPER_GAP`，按 `RED_PEG_CHANCE` 决定红或蓝。最下面一行左边蓝、右边红，把设计宽度四等分。抓住最上面那颗不再往前铺钉。蓝钉挂满 5 秒、红钉挂满 3 秒变灰，0.5 秒后恢复。计时细节在 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md)。

拉射的现行行为以 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md) 为准。包名是 `com.wangzhixuan.rubberband`，主屏幕名 Rubberband，避免盖掉别的底座包。

画面规则也在那里的「画面」一节。上下镜头用 `cameraDamp` 缓入缓出。左右镜头只在朝外拉时才偏。

结束分两种。回弹和摆动是动画，按下就打断。飞行是已经提交的一发，空中不能改。坠落是这一局的规则结束。角色隐藏，`#ui-root` 上的「再来一次」用下一个种子重开，并从掉下去的那个水平位置飞向出生钉。

底座仍在：`clientToDesign`、设计尺寸正交相机、`DoubleSide`、`base: './'`。`OrbitControls` 和挡住拖动的底部面板已经去掉。

## 验收

```bash
npx tsc --noEmit
npx tsx src/game/selftest.ts
```

自测覆盖：死区内松手不发射、向下拉满后脱开并向上飞、出手速率等于劲度乘伸长、向上拉满以同一速率向下飞、抓住后不超过拉长上限、拉出竖井时手臂仍指向钉子、锁定期内不抓回刚松开的钉。

浏览器里再看一遍：悬挂时能看见身体、两臂、下面一行三颗钉、上面正中的钉；点在身体附近就能拉，猴子当帧跟手；拉短取消；向上拉满能抓住上面那颗；从上面那颗向下拉能抓住下面那颗；向下飞出画面下沿才坠落；坠落后面板点「再来一次」才重开。无头 Chrome 画不出这块 WebGPU 画布，不能用它的截图当验收。
