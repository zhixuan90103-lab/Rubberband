# 拉射范围

现行规则在 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md)。代码在 `src/game/tune.ts`。这里只记做了什么、文件边界、以及还没做的。

## 已落地

按住、拉长、松手、收回、飞行、抓住或坠落。固定步长 1/60 秒。

| 模块 | 职责 |
|---|---|
| `src/game/tune.ts` | `feel` 和默认值。松弛长度、最长、钉位由它们算出 |
| `src/game/tunePanel.ts` | `#ui-root` 上的参数面板。写 `feel`，恢复默认 |
| `src/game/pegs.ts` | `nextPeg(prev, rng, id)` 是唯一摆钉入口 |
| `src/game/sim.ts` | Rapier 2D。重力、抓住和飞行的积分、左右墙 |
| `src/game/sling.ts` | 阶段、发射速率、抓住后的手臂力、转角、镜头 |
| `src/game/selftest.ts` | 死区、上下发射速率相同、抓取、旧钉锁、墙 |
| `src/main.ts` | WebGPU 场景、手臂、钉子、呼吸、指针。身体角度用 `body.spin` |

摆钉：只有两颗，都在竖井中线。下面那颗在挂着的脚的位置。上面那颗高出 `PEG_UPPER_GAP`。抓住上面那颗不再往前铺钉。

拉射的现行行为以 [PHYSICS-PLAN.md](./PHYSICS-PLAN.md) 为准。包名是 `com.wangzhixuan.rubberband`，主屏幕名 Rubberband，避免盖掉别的底座包。

画面：手臂在连着钉子时从当前钉弯到两肩，飞行中脱开。松手时旧钉闪一下，抓住时压扁。身体角度就是 `body.spin`，飞行中不变。绳子停住后只有大约 2 px 的呼吸。死区没有额外标志，只看手臂被拉多长。现在两颗钉都是蓝色。挂着、拉动、弹回时，镜头的目标是静止悬挂点。收回和飞行的目标是身体，收回时不会跟到悬挂点以下。飞过最下面那颗钉之后目标停住。镜头用 `CAMERA_DAMP` 缓入缓出，不在一帧里启动或停住。

结束分两种。回弹和摆动是动画，按下就打断。飞行是已经提交的一发，空中不能改。坠落是这一局的规则结束，只能重开。

底座仍在：`clientToDesign`、设计尺寸正交相机、`DoubleSide`、`base: './'`。`OrbitControls` 和挡住拖动的底部面板已经去掉。

## 验收

```bash
npx tsc --noEmit
npx tsx src/game/selftest.ts
```

自测覆盖：死区内松手不发射、向下拉满后脱开并向上飞、出手速率等于劲度乘伸长、向上拉满以同一速率向下飞、抓住后不超过拉长上限、拉出竖井时手臂仍指向钉子、锁定期内不抓回刚松开的钉。

浏览器里再看一遍：悬挂时能看见身体、两臂、下面的起点钉、上面正中的钉；拉短取消；向上拉满能抓住上面那颗；从上面那颗向下拉能抓住下面那颗；飞过最下面那颗才坠落；坠落后再点能重开。无头 Chrome 画不出这块 WebGPU 画布，不能用它的截图当验收。
