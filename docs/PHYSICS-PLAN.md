# 物理规则

数字的真源是 `src/game/tune.ts` 的 `feelDefaults`。面板 `src/game/tunePanel.ts` 改的是运行中的 `feel`，点「恢复」回到这组默认。范围见 [MVP-PLAN.md](./MVP-PLAN.md)。

坐标是设计像素，+x 向右，+y 向下。质量没有单独的旋钮，力都写成加速度。

## 一条手臂，两种用法

抓住和悬挂用同一股力。短于松弛长度时拉力是 0。长于它时，沿身体指向钉子：

```
松弛长度 = 挂稳长度 − 重力 / 劲度²
加速度 = 劲度² × (当前长度 − 松弛长度) + 径向阻尼 × 径向速度
```

切向阻尼只削垂直于手臂的速度，所以绕钉的摆会停。重力是世界重力，不在这股力里再加一份，也不在下落时加重。

最长长度是挂稳长度加 `maxPull`。拉动和抓住都停在这个长度上。

发射不用这股力积分。松手时记下拉过松弛长度的量和手臂方向。收回按无阻尼弹簧 `伸长 × cos(劲度 × 时间)` 走，到松弛长度脱手。出手速率是 `劲度 × 松手时的伸长`，方向是当时从身体指向钉子。重力、径向阻尼、手指移动的快慢都不改变这个速率。同样的长度，任何方向速率相同。松手同时给转速。拉满时是 `launchSpin`（默认 2 rad/s），短于拉满按伸长比例缩小。身体在钉子右侧就顺这一向转，在左侧就反向；正好在正下方时也转，方向取正。这个转速一直留到抓住。面板里叫「发射自转」。

## 默认数

| 名字 | 字段 | 默认 | 含义 |
|---|---|---|---|
| 挂稳长度 | `restDrop` | 60 px | 停住时钉心到身体中心 |
| 拉长上限 | `restDrop + maxPull` | 144 px | 钉心到身体的最长。`maxPull` 是 84 |
| 死区 | `minPull` | 25 px | 加在挂稳长度之外。不到这个，松手不发射 |
| 松弛长度 | `armSlack()` | 约 54.1 px | 由挂稳、重力和劲度算出，不是单独的数 |
| 劲度 | `armOmega` | 26 / 秒 | `sqrt(k/m)`。发射、抓住、悬挂共用 |
| 径向阻尼 | `radialDamp` | 17 / 秒 | 只在长于松弛长度时，沿手臂 |
| 切向阻尼 | `tangentDamp` | 9 / 秒 | 绕钉摆动。手臂拉力不管这个 |
| 重力 | `gravity` | 4000 px/s² | 一个值。朝设计 +y |
| 抓取半径 | `grabRadius` | 45 px | 身体中心进这个圆才抓住。瞄准辅助最多放到 70 px。两颗钉的圆心距不超过 140 px 时，放大后的范围会重叠，这一发不辅助 |
| 起手半径 | `grabStartRadius` | 120 px | 按下落在身体附近即可。当帧身体移到手指处 |
| 旧钉锁定 | `oldPegLock` | 0.18 秒 | 从进入飞行起算 |
| 墙弹性 | `wallRestitution` | 0.3 | 撞墙后留下的法线速度比例 |
| 镜头跟随 | `cameraDamp` | 0.3 秒 | 临界阻尼的时间 |
| 镜头冲出 | `cameraOvershoot` | 6 px | 越过目标后再走多远 |
| 悬挂锚点 | `pegAnchor` | 0.7 | 挂着的身体放在画面高度的这里 |
| 撞墙自转 | `hitSpin` | 0.002 | 每 px/s 的速度变化加多少 rad/s |
| 发射自转 | `launchSpin` | 2 rad/s | 拉满松手时的转速。短拉按伸长缩小 |
| 瞄准 / 抓住 / 挂稳转头 | `aimSpin` / `catchSpin` / `settleSpin` | 14 / 10 / 10 / 秒 | 头顶转到目标的弹簧率。抓住转头的规则在「转角和镜头」 |

按这组默认：最短能发射时身体离钉 85 px，出手约 804 px/s。拉满 144 px，出手约 2338 px/s。两个方向相同。

`SHOULDER`、`ARM_SAG` 现在的画面不读。钉的位置、跳跃范围和回收距离在下面「摆放」一节，数字在 `tune.ts`。

## 谁积分

`src/game/sim.ts` 用 Rapier 2D。固定步长 1/60，一步再拆成两小步，墙的反弹才能落在同一帧。这一版 Rapier 不会在 `step` 之后清掉用户力，所以每步末尾 `resetForces`。

| 阶段 | 做什么 |
|---|---|
| `drag` | 手指按住身体。不积分。超过拉长上限就沿钉子方向停住。碰到竖井边缘也沿这条方向缩短 |
| `return` | 同一股手臂力把身体拉回挂稳长度。按下可以打断 |
| `launch` | 不走 Rapier 的弹簧。按上面的无阻尼收回，到松弛长度写入出手速度，进入 `fly` |
| `fly` | Rapier。重力和墙。不加手臂力 |
| `hang` | 同一股手臂力，从抓住时的距离开始。速度够小、靠近正下方、长度接近挂稳时，收到挂稳姿势 |
| `fall` | 身体向下离开画面下沿，并且已经低于最下面的钉子，才不再积分。朝上飞过画面下沿不算死亡。角色、手臂和影子都隐藏。点「再来一次」用下一个种子重开 |
| 重开 | 不是新阶段。`respawnFlight` 给出一次普通 `fly`：速率是拉满发射的 0.8 倍，水平位置是掉落时的 x（墙内留一个身体半径），飞回死亡时 `heldId` 那颗钉。飞行中转一圈，然后走原来的抓住 |

不用 Rapier 的 `SpringJoint`（短于目标长度会推）和 `RopeJoint`（没有挂稳长度，也不按拉长蓄力）。

## 钉子和墙

钉子不吸引飞行中的身体。同时进入多颗的抓取范围时，抓最近的一颗。这一发若锁了一颗瞄准钉，只有那颗用放大后的半径，其余仍是 `grabRadius`。

## 触控

判定在 `src/main.ts`，抓住和发射在 `sling.ts`。出手速率不看手指移动的快慢。

| 判断 | 规则 |
|---|---|
| 抓住 | 阶段是 `hang` 或 `return`。设计坐标不在画面底边 `DRAG_BLOCK_Y` 以下。离身体不超过 `grabStartRadius`。钉子没在冷却。通过后同一帧跟手，并记下这根指针 |
| 瞄准 | 只有这根指针的移动能拉动。拉过上限就停在上限上 |
| 取消 | 这根指针抬起时，先用抬起坐标再摆一次身体。超过挂稳长度不足 `minPull` 就进入 `return` |
| 发射 | 抬起点超过 `minPull` 才进入 `launch`。方向和长度用抬起点，不用上一拍的移动点 |
| 另一根手指 | 移动和抬起都忽略。不能在第一根还按着时发射 |
| 系统取消 | `pointercancel` 进入 `return`，不发射，也不开始钉子冷却 |
| 已经出手 | `launch`、`fly`、`fall` 不再开始新的拉。点画面不重开 |

画面底边用设计坐标，在加上镜头偏移之前判断。`tryBeginDrag` 里的世界坐标比较不是这条底边。

长按不出系统放大镜：`html, body` 有 `-webkit-touch-callout: none`。页面滚动和捏合缩放已经关掉。iOS 底边上滑回主屏幕时，`BridgeViewController.preferredScreenEdgesDeferringSystemGestures` 返回 `.bottom`。第一次上滑交给游戏，紧接着再滑一次才回主屏幕。

## 瞄准辅助

玩家看不见弹道时，松手仍按真实飞行选一颗钉，只放宽那一颗的抓住范围。不改出手方向和速率。

曲线从松弛长度上的脱手点出发。初速是 `劲度 × 伸长`，方向从身体指向钉子再继续向前。之后只有重力和左右墙的反弹。它不画成皮筋的直线。

松手时沿这条曲线看还能抓的钉子，取离曲线最近的一颗：

- 最近距离已经在 `grabRadius`（45 px）里，半径不变。
- 超出 45 px、但不超过 70 px，这颗的抓住半径放到 70 px。`AIM_EXTRA` 是 25。
- 更远则不放大。
- 另一颗也在 70 px 以内，并且两颗圆心距不超过 140 px（两个 70 px 的圆会重叠），这一发不放大。圆心距超过 140 px 时，即使瞄准落在两颗中间，仍然放大更近的那一颗。

放大在松手时锁进 `aimId` 和 `aimRadius`，飞行中不再改。抓住或取消后清掉。瞄准过程里的曲线只用于当时的预览。

参数面板的「显示辅助」默认关闭（`guides.show`）。打开后同时显示抓取范围圈、身体中心点、拖动时的曲线。关掉只隐藏这些，不关掉上面的辅助。

刚脱开的钉要锁定期走完，并且身体曾经离开过它的抓取范围，才能再抓。

左右墙的内侧面和石头贴图的内边缘对齐，在设计屏外各 `WALL_FACE_OUT`（12 px）。贴图是 `src/assets/art/09-wall-slice.png`，九宫格铺在屏幕外，采样停在最右一列透明白像素之前。内侧阴影宽 36 px，70% 不透明，靠画面的 20% 淡出，并相对屏幕边再往外 24 px。身体是半径 `BODY_RADIUS` 的圆，中心最外停在墙内一个半径处（设计坐标大约 24 和 366）。撞墙弹开，不把手臂挂上去。弹性默认 `wallRestitution` 0.3。

### 摆放

开局铺编辑器里的开局卡：绿钉在脚下，其余钉保持卡上的相对位置。这页有草稿就用草稿，否则用 `levelDeck.json`。开局之后没有程序行。除衔接卡以外的普通卡打乱轮流往上接，一轮用完再洗牌，没有终点。接缝超过 300 px 时中间插一张衔接卡。规则在 [LEVEL-EDITOR.md](./LEVEL-EDITOR.md)「接缝和游戏里的叠卡」。

金币只来自卡上的点，不再按 `jumpsUntilCoin` 沿路撒币。

进了铆钉范围就接住。挂住时下一颗要露在顶上树叶下面才瞄得到。树叶大约盖住画面顶 **200 px**（`HANG_LEAF`），升高最多大约 **331 px**（`hangRise`）。卡内比这更高的一跳会把上面那颗钉留在树叶里。不在挂住或发射时临时补钉，也不删卡上的钉。

左右钉要留出朝墙拉开的余地。最短能发射的拉伸是挂稳长度加死区，85 px。身体中心又在墙内停住，所以钉不能贴到 x=48 那一档。现在最靠边的钉在 x=110，朝墙大约还能拉 86 px。

镜头不按这个跳跃范围锁定。飞行时镜头跟着角色。身体已经低于场上最下面那颗还在的钉之后，镜头停在那颗钉上，不再下移。再向下出画面下沿才进入 `fall`。上面或旁边还有钉也一样。

### 钉场窗口

活着的钉只覆盖镜头这一块，不按角色距离存一整条塔。

- 画面是 `cameraY` 到 `cameraY + 844`。
- 补行补到画面顶再往上 `PEG_FILL_LEAD`（半个 `PEG_JUMP_MAX` 再加 80 px，380 px）。这一段盖住新一行和上一行的中点，金币在进画面之前就已经摆好。
- 保留带再往上一个 `PEG_JUMP_MAX`（600 px）。卡组游玩再加一整屏（844 px），一张高卡的顶钉不会在下一拍被收回。
- 画面底再往下 `PEG_KEEP_BELOW`（一个 `PEG_JUMP_MAX`，600 px）以外收回，好让画面底下那一跳的目标还在。
- 手里的钉和刚离开的钉留着，即使已经出带。
- 槽满了还要往上补时，先收回已经在画面下面的钉。
- 最上面一行没了，从还活着的最高钉接着摆，规划器停在 `run`，不再重放出生行。
- 一场里一颗钉都没有时，规划器回到 `start`，重新摆出生钉。
- 卡组叠卡见 [LEVEL-EDITOR.md](./LEVEL-EDITOR.md)「接缝和游戏里的叠卡」。短接缝按 844 px 整屏，长接缝用衔接卡收到 300 px 以内。

槽位是固定的 `PEG_POOL`（24）个，数据和画面各一份、按下标对齐。回收把槽位标成空并停到场外；补行只改这个槽的坐标和颜色，不新建 Peg、不新建 mesh。贴图每张只加载一次，所有槽共用。空槽隐藏。层级是底盘、手臂、彩钉：底盘在手臂后面，彩钉盖在手臂前面。WebGPU 上未加载完的透明贴图不画，底盘另有圆垫。

重开是 `createWorld` 再 `beginEnter`：新的出生钉，从落下的 x 飞向这颗钉。镜头在身体还低于最低钉时停在钉场上，所以入场时画面里仍有钉。

### 金币

金币是卡上写好的点，摆卡时一起摆上。飞行途中和抓住时都不新生成。规则在 `src/game/coins.ts`，计数在 `SlingWorld.coinsGot`，世界画面在 `src/main.ts`，左上角计数在 `#ui-root` 的 `#coin-hud`（`src/style.css`）。吃到一枚响一声瞬态震动，见 [HAPTICS.md](./HAPTICS.md) §8。

摆放：

- 用卡上的本地坐标，跟这张卡的钉同一套原点。不按行数另撒。
- 横坐标夹进竖井，左右各留出身体半径加 36 px。
- 池子满了这枚就不摆。卡上的钉仍然都摆。

拾取和回收：

- 身体中心进入 `COIN_PICKUP + BODY_RADIUS`（36 + 36）才算捡到。`drag` 和 `return` 拉动时就算，当场开始飞向计数。`launch` 或 `fly` 仍要 `vy < 0`（正在向上）。往下穿过不算。
- 捡到后不在原地消失。同一颗网格沿弧线飞向左上角图标，`COIN_FLY` 0.36 秒，然后槽位回池。
- 金币 y 落到画面下沿再往下 80 px 就收回。
- 池子 `COIN_POOL` 是 8。空槽停在场外。不新建金币对象，也不新建 mesh。

飞向计数：

- 起点是捡到那一帧的画面坐标。之后每帧把画面坐标加回当时的镜头，所以镜头继续上移时弧线仍留在画面上。
- 位移用二次贝塞尔，参数是 `t²`（先慢后快）。控制点在弦的中点，朝画面中心弯出。弯出量是弦长的 0.42，夹在 72 到 150 px。
- 大小从世界尺寸收到图标尺寸。途中额外放大 0.2，在飞行的 72% 结束。之后锁在图标大小，并改成正面那一帧。槽位在 `t = 1` 才释放，最后几帧已经对齐。
- 目标大小按图标的设计像素宽度除以 `COIN_W × (425 / 517)`。425/517 是正面金币在格子里的不透明宽度。
- 飞行中阴影不透明度从 1 收到 0。数字等这枚金币飞完才加。

画面：

- 序列帧是 `src/assets/art/14-coin-sheet.png`，3×3。播放顺序是格子 0、1、2、5、4、3、6、7、8。边长 `COIN_W` 45。
- 贴图在创建材质时绑上。每一帧是一块裁好 UV 的平面，换帧只换几何。不要用 `texture.offset`，也不要在材质建好之后再赋 `map`。这套 WebGPU 不会画没有贴图的透明面。
- 层级在彩钉前面：`renderOrder` 5，z 为 1，不写深度、不做视锥剔除。底盘、手臂、彩钉仍是底、手臂、彩钉。
- 接触阴影和猴子同一套比例：直径是边长的 0.88，实心 0.8，向右下偏 0.12 和 0.17 个边长。不透明度 0.32，比猴子的 0.5 更透。宽度跟着序列帧的不透明轮廓：正面 1，侧向约 0.56，最薄 0.24。右偏量随这一帧的宽度缩小。

左上角计数：

- 挂在 `#ui-root` 里，跟安全区留白。阶段、高度、拉力那行调试文字已去掉。
- 深色胶囊：高 40，右留白 28，底色 `rgba(28, 18, 10, 0.4)`。里面是正面金币和数量，间距 4。
- 图标 32.4，用同一张序列帧的第 0 格，裁掉格子四周的透明边。数量 22 px。
- 金币飞到后，图标 0.32 秒内放大到 1.38 再回到 1。同一时间叠一层加色（`plus-lighter`），放大到 1.85 并淡出。

### 铆钉计时

每颗蓝钉和红钉只有两个状态。绿色出生钉不进入这套。

- 可用。只有猴子正挂着时才累计 `age`。悬挂、拉动、弹回都算挂着。弹回不是松手。
- 冷却。两条路进来：挂满 `BLUE_PEG_LIFE`（5 秒）或 `RED_PEG_LIFE`（3 秒），或者松手发射。一进来就变灰，抓不住，已经走的倒计时作废。手里正挂着的钉在变灰这一帧松开，猴子下落。`cool` 自己走，满 `PEG_INVALID`（0.5 秒）后 `age` 和 `cool` 都清零，回到可用，下次从满时间再计。

画面上每颗钉都有深色底。底不随颜色消失。彩色层是绿、蓝、红或灰里的一张，和底对齐，尺寸都是 41.6×39.7，是原来的 80%。剩下不到 `PEG_WARN`（2 秒）时，叠 `12-peg-flash.png`。它和铆钉同一张 129×123 画布，尺寸也跟着缩小。蓝钉把它着成浅色蓝，红钉着成浅色红：85% 白、15% 钉心颜色，再乘 1.5，亮起时接近白。WebGPU 加法混合。透明度在 0 和 1 之间来回。频率从每秒 2 次加到 12 次。没挂在这颗钉上时不闪。

## 转角和镜头

`body.spin` 绕身体自己的中心，转速 `spinVel` 在换动作时不清零。瞄准、抓住、挂稳是同一条临界阻尼弹簧，只换目标角和弹簧率。拖拽和松手弹回的目标是头顶朝向当前钉子，走最近的一侧。松手把 `spinVel` 设成发射滚动，飞行中只累加这个转速；撞墙把速度变化乘 `hitSpin` 再加进去。重开的那一飞把 `spinVel` 设成刚好转一圈。按下会打断抓住，弹簧接着转向钉子。

抓住后的朝向是 `CatchFacing`，和手臂分开，三态：

| 状态 | 什么时候 | 身体怎么转 |
|---|---|---|
| `watch` | 刚抓住 | 不设新目标。只保留飞行里的 `spinVel` |
| `arc` | 绳子摆起来 | 锁定一条长弧，转到头顶朝上。已经朝上也转满一圈 |
| `settle` | 冲势先停，绳子几乎没动 | 收到最近的头顶朝上，弹簧率是 `settleSpin` |

摆起来的标准是两条里的一条：身体离开抓住那一点 `CATCH_SWING_MOVE`（72 px），或绕钉转过 `CATCH_SWING_ANGLE`（1.05 rad，约 60°）。长弧的方向跟切向速度；正对钉、几乎没有切向时，取来势竖向的反向。目标在进入 `arc` 时定死。弹簧率是 `catchSpin` 乘以来势：满拉出手用满速，几乎停住时降到四成。来势只改快慢。

不看这一发拉了多远，也不用碰上那一帧的速度决定转不转。正对下一颗钉、来势大约 500 px/s 时，绳子往往只挪三十多像素，停在 `settle`。从侧面荡进去，或力量够带着翻过钉，才进 `arc`。挂稳之后仍是最近的头顶朝上。

镜头世界坐标是 `cameraY`，画面顶边在这里。盯住的高度是 `pegAnchor`。挂着和拉动时目标是悬挂点。发射和飞行时目标是身体，发射不会把目标放到悬挂点以下。飞过最下面那颗钉之后目标停住。这条线不画。

左右是 `cameraX`，和上下用同一套跟随时间。默认是 0。只有同时满足这两条才离开 0：手里的钉在中线范围外面，并且正在把身体朝靠近的那面墙拉。中线范围是 `|钉x - 竖井中线| ≤ CAMERA_HOLD_HALF`（70 px），不认「正中那一颗」。挂着、朝井里拉、松手弹回、发射和飞行都是 0。偏移量是朝墙多拉出的距离乘 `CAMERA_X_GAIN`（0.55），最多 `CAMERA_X_MAX`（36 px）。这样朝墙拉满时能看见一截石头。背景图等比例放大到 1.24，盖住镜头偏出去的缝。

掉落进入 `fall` 时镜头再震一次。位移加在 `camera.position` 上，不加进 `cameraX`、`cameraY`，也不加进丛林滚动和 `#ui-root`。同一次掉落只触发一回。0.34 秒。振幅是剩余时间比例的平方。第一下沿掉落方向，向下最多 10 px；左右用另一条相位，最多 3.5 px。结束时偏移是 0。相机不绕自身转。

## 画面

这些只改画面，不改出手速度和墙的位置。

- 动画随时可被按下打断。抓住后的起伏也算。飞行是已经出手的一发，不能改拉。坠落结算之后只能重开。
- 按下不必点中身体。`grabStartRadius` 内当帧把身体移到手指。
- 拉长时身体沿头顶到脚拉长，拉满到 1.2，左右宽度不变。手指拉过拉长上限、而且不是被墙挡住时，身体沿拉开的方向来回抖 1.5 px。手指画出画面也继续算拉满。这不改变身体位置，也不改变出手速率。被墙挡住、还没到上限时不抖。
- 抓住新钉时先压扁再沿头顶到脚拉长，然后回到原比例。两轴乘积为 1。按下就停。同时铆钉瞬间发亮，一圈外缘清楚、中间虚化的环向外扩开并消失。大约 0.36 秒。不改抓住的力。
- 绳子停稳后才播待机：大约 2 px 的起伏一直在。左右甩一次，然后只呼吸约 3 到 5 秒，再甩。甩之前约 0.4 秒眼睛先看向那一侧，甩的过程中一直看着。

### 飞行和撞墙的形变

只在 `fly`。悬挂、拖拽和拉满的 1.2 倍身长照旧。形变挂在身体的父节点上，沿速度方向，不沿头顶到脚。速度低于约 200 px/s 保持圆形，弧顶因此是圆的。再快才拉长，满速大约再长 9%。另一轴缩短，两轴乘积为 1。脚跟着这个形变，影子不跟着转。

撞墙看水平速度反向，并且撞前 `|vx| > 80`。顺序是：大约 0.03 秒收成圆形，大约 0.05 秒沿墙的法线压扁，大约 0.10 秒回到当时的飞行拉长。整段约 0.18 秒。撞得越狠越扁，最扁大约 0.89。不改弹开速度，也不改转速。

### 撞墙圆环

和抓住铆钉用同一张空心环、同一段 0.36 秒、同一种放大（从 0.72 放到约 2.6 倍）。底图是铆钉环的 1.75 / 1.15 倍。落在墙的内侧面、身体当时的高度上，左墙或右墙由撞上去的方向决定。颜色是墙体贴图的浅石色 `246, 233, 220`。不透明度是抓住那圈的 0.55 倍，仍按 `(1 - 进度)²` 淡出。加法混合，画在身体前面。

## 调参

`#ui-root` 里的「参数」面板写 `feel`。拉长上限滑杆改的是钉心到身体的总长度，不是 `maxPull` 本身。松弛长度和最长显示在面板顶上，由公式算出。「显示辅助」不写进 `feel`，默认关闭。
