# 物理规则

数字的真源是 `src/game/tune.ts` 的 `feelDefaults`。面板 `src/game/tunePanel.ts` 改的是运行中的 `feel`，点「恢复」回到这组默认。范围见 [MVP-PLAN.md](./MVP-PLAN.md)。

坐标是设计像素，+x 向右，+y 向下。质量没有单独的旋钮，力都写成加速度。

## 一条手臂，两种用法

抓住和悬挂用同一股力。短于松弛长度时拉力是 0。长于它时，沿身体指向钉子：

```
松弛长度 = 挂稳长度 − 重力 / 劲度²
加速度 = 劲度² × (当前长度 − 松弛长度) + 径向阻尼 × 径向速度
```

切向阻尼只削垂直于手臂的速度，所以绕钉的摆会停。重力是世界重力，不在这股力里再加一份，也不在下落时加重。

最长长度是挂稳长度加 `maxPull`。拉动和抓住都停在这个长度上。

发射不用这股力积分。松手时记下拉过松弛长度的量和手臂方向。收回按无阻尼弹簧 `伸长 × cos(劲度 × 时间)` 走，到松弛长度脱手。出手速率是 `劲度 × 松手时的伸长`，方向是当时从身体指向钉子。重力、径向阻尼、手指移动的快慢都不改变这个速率。同样的长度，任何方向速率相同。

## 默认数

| 名字 | 字段 | 默认 | 含义 |
|---|---|---|---|
| 挂稳长度 | `restDrop` | 61 px | 停住时钉心到身体中心 |
| 拉长上限 | `restDrop + maxPull` | 145 px | 钉心到身体的最长。`maxPull` 是 84 |
| 死区 | `minPull` | 25 px | 加在挂稳长度之外。不到这个，松手不发射 |
| 松弛长度 | `armSlack()` | 约 55.1 px | 由挂稳、重力和劲度算出，不是单独的数 |
| 劲度 | `armOmega` | 26 / 秒 | `sqrt(k/m)`。发射、抓住、悬挂共用 |
| 径向阻尼 | `radialDamp` | 16.6 / 秒 | 只在长于松弛长度时，沿手臂 |
| 切向阻尼 | `tangentDamp` | 8 / 秒 | 绕钉摆动。手臂拉力不管这个 |
| 重力 | `gravity` | 4000 px/s² | 一个值。朝设计 +y |
| 抓取半径 | `grabRadius` | 36 px | 身体中心进这个圆才抓住 |
| 起手半径 | `grabStartRadius` | 64 px | 按下要落在身体附近 |
| 旧钉锁定 | `oldPegLock` | 0.18 秒 | 从进入飞行起算 |
| 墙弹性 | `wallRestitution` | 0.9 | 撞墙后留下的法线速度比例 |
| 镜头跟随 | `cameraDamp` | 0.36 秒 | 临界阻尼的时间 |
| 镜头冲出 | `cameraOvershoot` | 6 px | 越过目标后再走多远 |
| 悬挂锚点 | `pegAnchor` | 0.7 | 挂着的身体放在画面高度的这里 |
| 撞墙自转 | `hitSpin` | 0.015 | 每 px/s 的速度变化加多少 rad/s |
| 瞄准 / 抓住 / 挂稳转头 | `aimSpin` / `catchSpin` / `settleSpin` | 14 / 10 / 8 / 秒 | 头顶转到目标的弹簧率 |

按这组默认：最短能发射时身体离钉 86 px，出手约 804 px/s。拉满 145 px，出手约 2338 px/s。两个方向相同。

`SHOULDER`、`ARM_SAG` 现在的画面不读。`PEG_X_SPREAD`、`PEG_GAP_MIN`、`PEG_GAP_MAX`、`RED_PEG_CHANCE` 是旧的刷钉，当前两颗钉不用。

## 谁积分

`src/game/sim.ts` 用 Rapier 2D。固定步长 1/60，一步再拆成两小步，墙的反弹才能落在同一帧。这一版 Rapier 不会在 `step` 之后清掉用户力，所以每步末尾 `resetForces`。

| 阶段 | 做什么 |
|---|---|
| `drag` | 手指按住身体。不积分。超过拉长上限就沿钉子方向停住。碰到竖井边缘也沿这条方向缩短 |
| `return` | 同一股手臂力把身体拉回挂稳长度。按下可以打断 |
| `launch` | 不走 Rapier 的弹簧。按上面的无阻尼收回，到松弛长度写入出手速度，进入 `fly` |
| `fly` | Rapier。重力和墙。不加手臂力 |
| `hang` | 同一股手臂力，从抓住时的距离开始。速度够小、靠近正下方、长度接近挂稳时，收到挂稳姿势 |
| `fall` | 不积分。点一下用下一个种子重开 |

不用 Rapier 的 `SpringJoint`（短于目标长度会推）和 `RopeJoint`（没有挂稳长度，也不按拉长蓄力）。

## 钉子和墙

场上两颗钉，都在竖井中线上。下面那颗在挂着的猴子脚的中心，`PEG_LOWER_Y = restDrop + LEG_DROP`。上面那颗再高出 `PEG_UPPER_GAP`（旧的 294 px，再加下面这颗到脚的距离，再加 3 个铆钉高度）。钉子不吸引飞行中的身体。同时进入多颗的抓取范围时，抓最近的一颗。

刚脱开的钉要锁定期走完，并且身体曾经离开过它的抓取范围，才能再抓。

左右墙在设计屏的两边。身体是半径 `BODY_RADIUS` 的圆。撞墙弹开，不把手臂挂上去。

## 转角和镜头

`body.spin` 绕身体自己的中心。拖拽、回弹、发射时头顶转向当前钉子。飞行中不转，撞墙另加一记 `hitSpin`。抓住后的旋转盖住冲过钉子和落回，停在头顶朝上。进度只增不减，弹簧率是 `catchSpin`，到了目标就停。挂稳后用 `settleSpin` 收到 0。

镜头世界坐标是 `cameraY`，画面顶边在这里。盯住的高度是 `pegAnchor`。挂着和拉动时目标是悬挂点。发射和飞行时目标是身体，发射不会把目标放到悬挂点以下。飞过最下面那颗钉之后目标停住。这条线不画。

## 调参

`#ui-root` 里的「参数」面板写 `feel`。拉长上限滑杆改的是钉心到身体的总长度，不是 `maxPull` 本身。松弛长度和最长显示在面板顶上，由公式算出。
