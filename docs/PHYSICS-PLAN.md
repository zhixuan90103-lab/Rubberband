# 物理实现

手感数字以 [SLING-KONG-FEEL.md](./SLING-KONG-FEEL.md) §7 和 `src/game/tune.ts` 为准。范围见 [MVP-PLAN.md](./MVP-PLAN.md)。

## 谁负责什么

`@dimforge/rapier2d-compat` 是直接依赖。坐标是设计像素，+y 向下。`src/game/sim.ts` 管这些：

- 世界重力 `(0, GRAVITY)`
- 飞行和收回的固定步积分。`simStep` 把一帧拆成两小步，墙的反弹才能在同一帧里发生
- 身体圆，半径 `BODY_RADIUS`，密度 1，摩擦 0，连续碰撞
- 左右墙。固定方块，内侧面在 `SHAFT_LEFT` 和 `SHAFT_RIGHT`，恢复系数 `WALL_RESTITUTION`，合成取最大

这一版 Rapier 不会在 `step` 之后清掉用户力。`simStep` 末尾调用 `resetForces`。不清的话，收回时加上的弹簧力会一直叠，脱开后速度无限变大。

`src/game/sling.ts` 管规则，不交给引擎：死区、360° 拉动、旧钉锁、抓哪颗钉、按下打断、抓住后的单侧皮筋、落稳后的定长绳子、身体转角、坠落重开。悬挂不用 Rapier 旋转关节。关节曾把身体留在钉子上方，并灌进很大的向上速度。

锁文件里的 `@dimforge/rapier3d-compat` 是 Three 的传递依赖。玩法不 import，也不要用于这一条平面规则。

| 阶段 | 积分 |
|---|---|
| `drag` | 手指按住，不积分 |
| `return` | 动画，回到钉子正下方。按下打断 |
| `launch` | Rapier。拉力 `LAUNCH_SCALE² × 伸长` 指向钉子，另加重力。伸长不超过 0 就脱开 |
| `fly` | Rapier。只剩重力，墙可以反弹 |
| `hang` 且正在抓住 | 单侧皮筋，见下文。任意发射方向同一条 |
| `hang` 且皮筋已落稳 | 定长绳子，长度锁在 `REST_DROP` |
| `fall` | 不积分。点一下重开 |

## 手臂

任意角度都走同一条，没有向上、向下各自的方法。

发射只用 `LAUNCH_SCALE`。加速度指向钉子，大小是 `LAUNCH_SCALE² × (长度 − HANG_DROP)`，只拉不推。长度回到 `HANG_DROP` 就脱开。

抓住后速度乘 `CATCH_KEEP`（现在是 1）。皮筋的静止长度是 `REST_DROP`，不是 `HANG_DROP`。短于 `REST_DROP` 没有拉力。长于它，加速度是 `BAND_RATE² × (长度 − REST_DROP)`，并减去径向的普通重力，所以平衡就在 `REST_DROP`，不会再被重量拉长一截。径向阻尼是 `BAND_DAMP`。长度超过 `REST_DROP × 2` 时贴回这个圆，速度改成这一帧实际位移。切向速度用 `CATCH_SWING_DAMP` 衰减，不碰径向弹簧。下落时重力加重到最多约 1.95 倍，只加在抓住和飞行上。落稳后的绳子用普通重力，避免下摆被越加越快。

这些率数写在 `sling.ts` 的 `stepArm` 旁边，不读 `tune.ts` 里的 `ARM_RATE`、`ARM_DAMP`、`SWING_DAMP`。那三个常数留着，当前手臂不用。

| 常数 | 值 | 用在 |
|---|---|---|
| `BAND_RATE` | 14 / 秒 | 抓住后皮筋的 `sqrt(k)` |
| `BAND_DAMP` | 18 / 秒 | 径向回弹 |
| `CATCH_SWING_DAMP` | 5 / 秒 | 抓住后绕钉摆动 |
| `ROPE_DAMP` | 8 / 秒 | 落稳后的绳子，大约回一次就停 |
| `BAND_MAX` | `REST_DROP × 2` | 皮筋最长 |

皮筋结束的条件：已经过了最远点、身体在钉子下方、长度离 `REST_DROP` 不到 4 px、速度低于 40 px/s。最高点附近又慢又接近一臂长，不能在那里结束。结束后绳子锁在 `REST_DROP`。偏角小于约 3° 且速度低于 16 px/s 时，钉在钉子正下方，剩余速度清掉。

## 转角

身体只有一个角 `body.spin`，绕自己的中心。画面画这个角。手臂在连着钉子时始终指向钉子，不跟着身体转。

拖拽、死区回位、发射时，头顶用弹簧转向当前钉子。飞行中不转。撞墙只反弹水平速度。

旋转从抓住开始，盖住过冲和回落两段，终点是头顶朝上：

- 进度在往前冲时跟着沿抓住方向剩下的速度，走到一半。
- 回落时跟着离悬挂点的距离，走到满。进度只增不减。
- 目标角度是出发角度加上「到头顶朝上」的转角，再乘 `min(1, 进度 × 1.15)`，所以会在回落结束前先到。
- 已经离头顶朝上不到约 0.9 rad 时，顺着抓住的切向再转一整圈，然后停在头顶朝上。离得更远就只走较短的那一侧，不超过半圈，不再多转一圈。
- 角度用弹簧跟上目标（`followSpin`，每秒 10），到了目标就停，不转过头。

落稳之后如果还没完全到头顶朝上，悬挂再用一根较慢的弹簧收到 0。收到越过 0 的那一帧钉在 0。

绳子停住、速度不超过 8 px/s 时，身体只做大约 2 px 的呼吸，不再绕钉子甩第二段。

## 镜头

镜头的世界坐标是 `cameraY`，画面顶边在这里。盯住的点放在画面高度 `PEG_SCREEN_ANCHOR`（0.7）。挂着、拉动、弹回时目标是静止悬挂点。收回和飞行时目标是身体中心，收回阶段不会把目标放到悬挂点以下。飞过最下面那颗钉之后目标停住。镜头用 `CAMERA_DAMP` 做临界阻尼去追目标，所以启动和停止会缓入缓出，匀速时人仍在这条线上。这条线不画出来。

## 还没有拆开的量

| 量 | 现在怎么体现 |
|---|---|
| 质量 `m` | 折进加速度。Rapier 身体密度是 1，弹簧力再乘质量，所以改密度不会改变发射加速度 |
| 劲度 `k` | 发射是 `LAUNCH_SCALE²`。抓住后的皮筋是 `BAND_RATE²` |
| 阻尼 | 皮筋径向 `BAND_DAMP`，抓住摆动 `CATCH_SWING_DAMP`，落稳绳子 `ROPE_DAMP`。都是直接乘在速度上 |
